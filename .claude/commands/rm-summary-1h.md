# Ask Revenium for AI spending summary (last hour)

Get comprehensive breakdown of the last hour's spending across all cost dimensions from Revenium.

Use the business_analytics_management tool with these parameters:
- action: "get_cost_summary"
- period: "HOUR"
- group: "TOTAL"

## Use Case
Quick check on recent spending, real-time cost monitoring, immediate budget awareness.

## Deliverables
Review the output of the tool call and provide the user a comprehensive overview of all information provided.
