# Ask Revenium for AI spending summary (last 24 hours)

Get comprehensive breakdown of the last 24 hours spending across all cost dimensions from Revenium.

Use the business_analytics_management tool with these parameters:
- action: "get_cost_summary"
- period: "TWENTY_FOUR_HOURS"
- group: "TOTAL"

## Use Case
Complete daily financial picture for stakeholder updates, end-of-day reporting, comprehensive cost awareness across all spending categories.

## Deliverables
Review the output of the tool call and provide the user a comprehensive overview of all information provided.
