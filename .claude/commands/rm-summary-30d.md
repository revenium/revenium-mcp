# Ask Revenium for AI spending summary (last 30 days)

Get comprehensive breakdown of the last 30 days spending across all cost dimensions from Revenium.

Use the business_analytics_management tool with these parameters:
- action: "get_cost_summary"
- period: "THIRTY_DAYS"
- group: "TOTAL"

## Use Case
Monthly cost review, budget reconciliation, executive reporting, long-term trend analysis.

## Deliverables
Review the output of the tool call and provide the user a comprehensive overview of all information provided.
