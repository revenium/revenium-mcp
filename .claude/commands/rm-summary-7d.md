# Ask Revenium for AI spending summary (last 7 days)

Get comprehensive breakdown of the last 7 days spending across all cost dimensions from Revenium.

Use the business_analytics_management tool with these parameters:
- action: "get_cost_summary"
- period: "SEVEN_DAYS"
- group: "TOTAL"

## Use Case
Weekly cost review, trend analysis, budget planning and team updates.

## Deliverables
Review the output of the tool call and provide the user a comprehensive overview of all information provided.
