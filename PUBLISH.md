# Publishing revenium-mcp to the official MCP registry

Registry: https://registry.modelcontextprotocol.io. Schema: https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json

`server.json` and this guide live in the internal repository and reach the public mirror with every release, like the rest of the package. Publish from the public repository root after the release that carries the version named in `server.json`.

## Who runs this
A GitHub member of the `revenium` organization with public membership, because the `io.github.revenium/*` namespace is proven by GitHub login.

## Steps
1. Release the version named in `server.json` to PyPI. The registry reads the PyPI description of that exact version and checks it for `mcp-name: io.github.revenium/revenium-mcp`, the HTML comment at the end of `README.md`. PyPI does not accept a re-upload of an existing version, so a version released before the comment existed cannot be listed. To list only the hosted endpoint, delete the `packages` entry from `server.json` in a committed change; the unit test accepts a manifest without packages.
2. Install the CLI:
   ```bash
   brew install mcp-publisher
   ```
3. Log in as a member of the organization:
   ```bash
   mcp-publisher login github
   ```
4. Publish from the public repository root:
   ```bash
   mcp-publisher publish
   ```

## Alternative name: io.revenium/revenium-mcp
Use this to show the domain in the listing. A domain-based name is the reverse-DNS form of the domain proven, so `revenium.io` proves `io.revenium/*` and `revenium.ai` proves `ai.revenium/*`. It needs a DNS TXT record on the apex of `revenium.io` (not under a selector), generated by `mcp-publisher` from a key pair:
```
revenium.io. IN TXT "v=MCPv1; k=ed25519; p=<PUBLIC_KEY>"
```
Then `mcp-publisher login dns --domain revenium.io --private-key <PRIVATE_KEY>`. Change `name` to `io.revenium/revenium-mcp` in `server.json` and the `mcp-name` line in `README.md` to match, in one committed change: `tests/unit/test_mcp_registry_manifest.py` requires the README comment to repeat the manifest's name. Confirm the domain that owns the product before choosing this route.

## Verify
```bash
curl 'https://registry.modelcontextprotocol.io/v0/servers?search=revenium'
```
The response lists `io.github.revenium/revenium-mcp` with the remote `https://mcp.revenium.ai/mcp` and the PyPI package.

## Later releases
The Version Bumping steps in `DEVELOPMENT.md` include `server.json`: its top-level `version` and every `packages[].version` must equal `version` in `pyproject.toml`, and `tests/unit/test_mcp_registry_manifest.py` fails the unit suite when they drift. Publish again after each release.
