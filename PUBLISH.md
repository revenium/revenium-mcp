# Publishing revenium-mcp to the official MCP registry

Registry: https://registry.modelcontextprotocol.io. Schema: https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json

## Who runs this
A GitHub member of the `revenium` organization with public membership, because the `io.github.revenium/*` namespace is proven by GitHub login.

## Steps
1. Merge the change that adds `server.json` and the `mcp-name` line in `README.md`.
2. Release a new version of the package to PyPI so the published README carries the `mcp-name` line, then set both `version` fields in `server.json` to that release. The registry reads the PyPI description of the exact version named in `server.json` and checks it for `mcp-name: io.github.revenium/revenium-mcp`. Version 0.10.0 is already on PyPI without the line, and PyPI does not accept a re-upload of an existing version, so publishing with 0.10.0 fails this check. Skip this step by deleting the `packages` entry and publishing the hosted endpoint only.
3. Install the CLI:
   ```bash
   brew install mcp-publisher
   ```
4. Log in as a member of the organization:
   ```bash
   mcp-publisher login github
   ```
5. Publish from the repository root:
   ```bash
   mcp-publisher publish
   ```

## Alternative name: io.revenium/revenium-mcp
Use this to show the domain in the listing. A domain-based name is the reverse-DNS form of the domain proven, so `revenium.io` proves `io.revenium/*` and `revenium.ai` proves `ai.revenium/*`. It needs a DNS TXT record on the apex of `revenium.io` (not under a selector), generated by `mcp-publisher` from a key pair:
```
revenium.io. IN TXT "v=MCPv1; k=ed25519; p=<PUBLIC_KEY>"
```
Then `mcp-publisher login dns --domain revenium.io --private-key <PRIVATE_KEY>`. Change `name` to `io.revenium/revenium-mcp` in `server.json` and the `mcp-name` line in `README.md` to match. Confirm the domain that owns the product before choosing this route.

## Verify
```bash
curl 'https://registry.modelcontextprotocol.io/v0/servers?search=revenium'
```
The response lists `io.github.revenium/revenium-mcp` with the remote `https://mcp.revenium.ai/mcp` and the PyPI package.

## Later releases
Update `version` in `server.json` (both places) to match `pyproject.toml`, then publish again.
